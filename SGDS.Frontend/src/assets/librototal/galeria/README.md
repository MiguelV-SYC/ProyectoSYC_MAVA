# Galería de arte y cultura — Libro Total

Coloca las fotos de cada sede en su carpeta correspondiente. `GaleriaCultural.tsx`
las carga automáticamente (formatos jpg/jpeg/png/webp) — no hace falta tocar código
ni reiniciar el servidor, solo copiar los archivos.

- `bucaramanga/`
- `san-gil/`
- `barrancabermeja/`
- `sincelejo/`
- `neiva/`
- `arauca/`
- `armenia/`
- `mocoa/`
- `riohacha/`

Las imágenes de una carpeta se muestran en orden alfabético por nombre de archivo
(ej. `01-mural.jpg`, `02-terminal-lectura.jpg`, ...) y rotan automáticamente cada 8
segundos en la vista de detalle de la sede.
